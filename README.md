# SIKHAR NER - AI Landslide Risk Monitoring

**Smart India Hackathon 2025** | PS ID: 26001

## Live Demo
https://shamil-haniy.github.io/sih-landslide-ner/

## Features
- AI-powered landslide risk prediction
- 32 locations across 8 NER states
- Monsoon scenarios (Dry/Normal/Heavy/Cloudburst)
- Multilingual alerts (6 languages)
- PDF/Text reports
- Offline-capable PWA

## Data Sources
- ISRO CartoDEM, IMD rainfall, GSI Bhusanket
